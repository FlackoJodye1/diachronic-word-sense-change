# Data Directory

## Structure

- `processed/germanet/` - Enhanced GermaNet data (main output)
- `dwds_contexts/` - Real German corpus sentences  
- `external/germanet_v190/` - Original GermaNet data
- `raw/` - Source target word lists

## Key Files

- `processed/germanet/wsd_senses_enhanced.csv` - **Main enhanced dataset**
- `dwds_contexts/fetch_progress_25_words.jsonl` - Real corpus sentences
- `processed/dwds/real_wsd_evaluation_results.json` - Evaluation results
